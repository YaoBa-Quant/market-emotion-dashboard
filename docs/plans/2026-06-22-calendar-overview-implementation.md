# 日历总览页实施计划

日期: 2026-06-22
关联设计: `docs/plans/2026-06-22-calendar-overview-design.md`
执行方式: 当前会话手工执行

## 目标

在保留现有历史详情页的基础上，新增一个“日历总览页”，支持:

- 默认仍进入最近交易日详情页
- 顶部切换 `详情 | 日历总览`
- 月历展示交易日摘要状态
- 对未缓存交易日执行按日抓取
- 在日历页展示 `沪深300 + 建议仓位` 趋势图

## 任务拆分

### 任务 1: 扩展后端存储与摘要查询

- 为 `snapshotStore.js` 增加按月份/区间读取已缓存快照摘要能力
- 仅返回日历页与趋势图所需字段，避免前端自己遍历完整详情
- 验证:
  - 能拿到某月已有缓存日期集合
  - 能拿到区间趋势序列

### 任务 2: 新增后端日历接口

- 新增 `GET /api/market/calendar/summary?month=YYYYMM`
- 新增 `GET /api/market/calendar/trend?range=1m|3m|6m|1y`
- 新增 `POST /api/market/emotion/fetch`
- 复用现有历史抓取与缓存逻辑，不引入新数据源
- 验证:
  - 已缓存交易日返回 `ready`
  - 未缓存交易日返回 `missing`
  - `fetch` 可写入快照并返回成功

### 任务 3: 前端页面状态与服务层改造

- 扩展 URL 状态为 `page/date/month`
- 将现有详情页逻辑拆成独立视图
- 新增日历页数据请求方法
- 验证:
  - 默认进入详情页
  - 详情页与日历页切换后 URL 正确
  - 浏览器前进/后退可恢复状态

### 任务 4: 实现日历页 UI

- 实现顶部页签切换
- 实现月历网格
- 实现缺失日、错误日、非交易日、已缓存日样式
- 实现趋势图组件
- 验证:
  - 日历月切换正常
  - 点击 `ready` 进入详情页
  - 点击 `missing` 触发抓取

### 任务 5: 联调与回归验证

- 验证详情页原有内容不回归
- 验证日历摘要、补抓、趋势图联动
- 验证接口返回和页面错误态
- 验证:
  - `/api/market/emotion/history` 正常
  - `/api/market/calendar/summary` 正常
  - `/api/market/calendar/trend` 正常
  - `/api/market/emotion/fetch` 正常

## 执行顺序

1. 先做任务 1 和任务 2
2. 再做任务 3 和任务 4
3. 最后做任务 5

## 备注

- 当前阶段不引入 `vue-router`
- 当前阶段不新增摘要表，先从 `market_emotion_snapshots` 派生
- 若趋势接口性能不足，再考虑摘要持久化优化
